# GPS AutoClick v0.6

Funzioni:
- GPS simulato con coordinate manuali.
- Selezione dell'app installata.
- Click automatico via Accessibilità con fallback gesture.
- 4 automazioni indipendenti.
- Per ogni automazione: ON/OFF, ora, app, testo del tasto, latitudine e longitudine.
- Ripristino degli orari dopo il riavvio del telefono.
- Supporto agli allarmi esatti quando autorizzati da Android.

Per usare la posizione fittizia selezionare GPS AutoClick nelle Opzioni sviluppatore.
Per il click automatico attivare GPS AutoClick in Accessibilità.
